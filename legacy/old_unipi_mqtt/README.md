# Legacy reference (read-only)

The original `unipi_mqtt.py` (version 02.2021.1) that runs on the Neuron L513 today, kept for
reference while it is replaced by `hass-unipi.py`. Credentials and addresses are replaced by
placeholders. **Do not deploy.** The per-circuit config of the real installation is not
committed (house-specific); `unipi_mqtt_config.example.json` shows the format.
